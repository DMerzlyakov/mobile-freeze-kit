# MobileFreezeKit

Набор переиспользуемых библиотек на Kotlin Multiplatform для общих задач в приложениях. Модули предназначены для независимого подключения: можно использовать только нужные возможности.

## Статус

Проект находится на начальном этапе. Готовых библиотечных модулей и инструкций по подключению пока нет.

По мере появления модулей здесь будут доступны:

- описание возможностей каждого модуля;
- поддерживаемые платформы и требования совместимости;
- инструкции по подключению;
- примеры использования публичного API.
