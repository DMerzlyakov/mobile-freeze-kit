# Changelog

## 0.1.1 — 2026-11-04

### Исправлено

- Минимальная версия Android для `mvi` снижена с API 29 до API 24 (Android 7.0).
- Публичный API, зависимости и набор KMP targets сохранены. Для Android по-прежнему требуется compileSdk 37 или выше.

## 0.1.0 — 2026-10-26

### Добавлено

- Первая публикация `io.github.dmerzlyakov:freezekit-mvi` в Maven Central.
- MVI-контракты, ViewModel, обмен данными между экранами и Compose-интеграция lifecycle и событий.
- Поддержка Android (API 29+), JVM, `iosArm64` и `iosSimulatorArm64`.
